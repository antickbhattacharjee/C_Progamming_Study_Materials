# C Programming Curriculum

Welcome to the C Programming learning repository! This project has been structured into a comprehensive, day-by-day curriculum to guide you through the fundamental and advanced concepts of the C language.

## Course Structure

The curriculum is divided into 16 days, each containing a dedicated folder with source code, detailed theoretical explanations, block diagrams, and assignment questions with answers.

## How to Use This Repository

1. **Navigate Day-by-Day**: Start from Day 1 and progress sequentially. Each folder acts as an independent module.
2. **Read the Theory**: Open the `README.md` inside each daily folder to understand the concepts, visualize memory and execution flows via Mermaid diagrams, and read up on features and limitations.
3. **Run the Code**: Review the provided `.c` and `.cpp` source files and run them using your preferred C compiler (like GCC or MinGW).
4. **Practice**: Attempt to solve the Assignment Questions located in each daily README before looking at the provided answers to test your knowledge.
